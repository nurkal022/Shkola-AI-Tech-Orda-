# 🎬 Инструкции для Live Demo - Лекция 15 AutoGen

## Как использовать на лекции

### Вариант 1: Полная демонстрация

**Файл:** `00_live_demo_autogen.py`

**Как использовать:**
1. Запустите: `python 00_live_demo_autogen.py`
2. Файл покажет 9 этапов:
   - ЭТАП 1: Импорты
   - ЭТАП 2: Настройка LLM
   - ЭТАП 3: Создание первого агента
   - ЭТАП 4: Создание User агента
   - ЭТАП 5: Простой диалог
   - ЭТАП 6: Специализированные агенты
   - ЭТАП 7: Создание группового чата
   - ЭТАП 8: Создание GroupChatManager
   - ЭТАП 9: Запуск группового чата

**Преимущества:**
- Все объяснения встроены
- Автоматически показывает каждый этап
- Готовые примеры

---

### Вариант 2: Пошаговое переписывание

**Файл:** `00_live_demo_step_by_step.py`

1. Откройте файл в IDE
2. Раскомментируйте код по этапам
3. После каждого этапа запускайте и объясняйте

### Вариант 3: Демонстрация примеров

**Файлы:** `01_basic_two_agents.py` - `05_problem_solving.py`

**Что показывать:**

1. **01_basic_two_agents.py** (5 мин)
   - Простейший диалог двух агентов
   - Показывает базовые концепции

2. **02_group_chat.py** (10 мин)
   - Групповой чат с Writer, Critic, Editor
   - Показывает как агенты работают вместе

3. **03_specialized_agents.py** (10 мин)
   - Planner, Executor, Reviewer
   - Показывает специализацию агентов

4. **04_code_generation.py** (10 мин)
   - Генерация кода командой агентов
   - Практический пример

5. **05_problem_solving.py** (10 мин)
   - Решение сложных задач
   - Показывает мощь мультиагентных систем

## 💡 Советы для лекции

1. **Начните с простого**
   - Покажите диалог двух агентов
   - Объясните базовые концепции

2. **Затем усложняйте**
   - Добавьте третьего агента
   - Покажите групповой чат

3. **Покажите специализацию**
   - Каждый агент имеет свою роль
   - Агенты работают вместе

4. **Обратите внимание на:**
   - System message определяет роль
   - Human input mode контролирует взаимодействие
   - Speaker selection выбирает следующего
