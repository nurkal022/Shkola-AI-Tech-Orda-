## 🎯 Ключевые концепции

### Что такое ReAct?

```
ReAct = Reasoning + Acting

Агент работает по циклу:
  1. Thought (Размышление) - агент "думает вслух"
  2. Action (Действие) - выбирает инструмент
  3. Action Input (Ввод) - передаёт параметры
  4. Observation (Наблюдение) - получает результат
  5. ... (повторяется)
  6. Final Answer (Итоговый ответ)
```

### ReAct vs OpenAI Function Calling

| Аспект | ReAct Prompting | OpenAI Function Calling |
|--------|----------------|------------------------|
| **Прозрачность** | ✅ Видим все мысли | ⚠️ Меньше видимости |
| **Надёжность** | ⚠️ Может ошибиться в формате | ✅ Структурированный JSON |
| **Совместимость** | ✅ Любая LLM | ⚠️ Только OpenAI |
| **Отладка** | ✅ Легко понять что пошло не так | ❌ Сложнее |
| **Производительность** | ⚠️ Больше токенов | ✅ Эффективнее |

## 💡 Важные моменты

### 1. Verbose Mode критичен

Включите `verbose=True` чтобы видеть рассуждения агента:

```python
AgentExecutor(..., verbose=True)
```

Это помогает:
- Понимать как агент работает
- Отлаживать проблемы
- Обучать студентов

### 2. ReAct - это промпт-инжиниринг

ReAct не требует специальных API или функций. Это просто:
- Текстовый промпт с инструкциями
- LLM генерирует текст в заданном формате
- LangChain парсит текст и извлекает действия

### 3. Формат ответа критичен

LLM должна следовать строгому формату:
```
Thought: ...
Action: tool_name
Action Input: ...
Observation: ...
```

Если формат нарушен, LangChain может не распарсить ответ.

### 4. Ограничения ReAct

- Может ошибиться в формате (парсинг ошибок)
- Больше токенов (текстовый формат)
- Требует более мощных моделей для надёжности

### 5. Когда использовать ReAct

✅ **Используйте ReAct когда:**
- Нужна максимальная прозрачность
- Работаете с не-OpenAI моделями
- Важна обучаемость (студенты видят рассуждения)
- Нужен полный контроль над форматом

⚠️ **Используйте Function Calling когда:**
- Нужна максимальная надёжность
- Работаете только с OpenAI
- Важна производительность
- Нужна простота интеграции

## ❓ Часто задаваемые вопросы

**Q: ReAct работает только с OpenAI?**  
A: Нет! ReAct - это промпт-инжиниринг, работает с любой LLM.

**Q: Что надёжнее - ReAct или Function Calling?**  
A: Function Calling надёжнее (структурированный JSON), но ReAct прозрачнее.

**Q: Можно ли комбинировать ReAct и Function Calling?**  
A: Да, но обычно выбирают один подход для консистентности.

**Q: Как отладить агента если он ошибается?**  
A: Включите `verbose=True` и смотрите Thought/Action/Observation. Это покажет где агент ошибся.

**Q: Нужно ли кастомизировать ReAct промпт?**  
A: Не обязательно, стандартный промпт работает хорошо. Кастомизация нужна для специфичных задач.
