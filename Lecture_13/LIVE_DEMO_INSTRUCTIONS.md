## 💡 Советы для лекции

1. **Verbose mode критичен!**
   - Всегда используйте `verbose=True`
   - Это показывает Thought/Action/Observation
   - Студенты видят как агент думает

2. **Начните с простого**
   - Первый пример: "Сколько будет 25 * 17?"
   - Показывает базовый цикл ReAct
   - Легко понять

3. **Затем усложняйте**
   - Второй пример: "Какая сегодня дата? Умножь день на 10"
   - Показывает многошаговое рассуждение
   - Демонстрирует выбор инструментов

4. **Интерактивность**
   - Используйте интерактивный режим
   - Задавайте вопросы студентов агенту
   - Показывайте как агент обрабатывает разные запросы

5. **Обратите внимание на:**
   - Формат Thought/Action/Observation
   - Как агент выбирает инструменты
   - Как обрабатываются ошибки
   - Многошаговые рассуждения

## 🐛 Возможные проблемы

**Проблема:** Агент не выбирает правильный инструмент
**Решение:** Улучшите описание инструмента в docstring

**Проблема:** Ошибка парсинга
**Решение:** `handle_parsing_errors=True` уже включён

**Проблема:** Слишком много итераций
**Решение:** Уменьшите `max_iterations` или упростите задачу

**Проблема:** API ключ не найден
**Решение:** Проверьте `.env` файл
