# Лекция 18: Агент для углублённых исследований

## Описание

Применяем навыки создания агентов в практическом проекте — создаём полноценного агента-исследователя, который умеет:
- **Планировать** исследование: разбивает тему на подтемы и генерирует запросы
- **Собирать данные** из множества источников: Wikipedia, DuckDuckGo, GitHub, новости, веб-страницы
- **Синтезировать** информацию: объединяет находки в структурированные заметки
- **Генерировать отчёты** в разных форматах: для студентов, разработчиков, менеджеров

---

## Архитектура

```
[Тема] → Планировщик → Агент-Исследователь → Генератор отчётов → [Файл .md]
```

| Компонент | Роль |
|-----------|------|
| **Планировщик** | Разбивает тему на подтемы, генерирует поисковые запросы |
| **Агент-Исследователь** | Ищет по плану, собирает данные из нескольких источников |
| **Генератор отчётов** | Форматирует сырые данные в структурированный отчёт |

---

## Файлы

| Файл | Описание |
|------|----------|
| `00_live_demo.py` | **Live Demo** — простой агент (3 инструмента, для совместного написания) |
| `01_research_planner.py` | Планировщик — разбиваем тему на подтемы и запросы |
| `02_deep_research_agent.py` | **Главный файл** — полный пайплайн исследования |
| `03_report_generator.py` | Генератор отчётов в 4 форматах для разной аудитории |

---

## Инструменты агента

| Инструмент | Источник | Назначение |
|------------|----------|------------|
| `search_web` | DuckDuckGo | Общий поиск актуальной информации |
| `search_news` | DuckDuckGo News | Последние новости и тренды |
| `wikipedia_search` | Wikipedia API | Базовые определения и факты |
| `scrape_page` | BeautifulSoup | Детальное чтение веб-страниц |
| `github_search` | GitHub API | Поиск проектов и библиотек |
| `add_note` | Локально | Сохранение промежуточных заметок |
| `save_report` | Локально | Сохранение финального отчёта |

## Форматы отчётов

| Формат | Аудитория | Особенности |
|--------|-----------|-------------|
| `educational` | Студенты | Простой язык, аналогии, примеры |
| `technical` | Разработчики | Детали архитектуры, инструменты |
| `executive` | Менеджеры | Краткий (≤300 слов), выводы |
| `analytical` | Аналитики | SWOT, тренды, сравнения |

## Ключевые концепции

### Зачем планировать перед поиском?

```
Без плана:             С планом:
  ↓                      ↓
Случайный поиск        Структурированный поиск
  ↓                      ↓
Хаотичные данные       Целенаправленные данные
  ↓                      ↓
Плохой отчёт           Системный отчёт
```

### Разделение ответственности

```
Планировщик  →  "Что искать?"
Исследователь → "Как искать?"
Редактор      → "Как оформить?"
```

### Итеративное углубление

1. **Широкий поиск** (`search_web`) — общая картина
2. **Факты** (`wikipedia_search`) — проверяем определения
3. **Детали** (`scrape_page`) — углубляемся в важные страницы
4. **Тренды** (`search_news`) — актуальность 2025
5. **Инструменты** (`github_search`) — практическая сторона

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
# Простая демонстрация (живое кодирование)
python 00_live_demo.py

# Только планировщик
python 01_research_planner.py

# Полноценный агент (основной файл)
python 02_deep_research_agent.py

# Генератор отчётов (4 формата)
python 03_report_generator.py
```

## Результаты

Все отчёты сохраняются в папку `output/`:
- `research_*.md` — финальные отчёты по темам
- `report_llm_*.md` — отчёты в разных форматах
- `_notes.json` — промежуточные заметки агента
