# 🎬 Инструкции для Live Demo - Лекция 14 LangGraph

## Как использовать на лекции

### Вариант 1: Полная демонстрация простого графа

**Файл:** `00_live_demo_simple_graph.py`

**Как использовать:**
1. Запустите: `python 00_live_demo_simple_graph.py`
2. Файл покажет 7 этапов:
   - ЭТАП 1: Импорты
   - ЭТАП 2: Определение состояния
   - ЭТАП 3: Определение узлов
   - ЭТАП 4: Создание графа
   - ЭТАП 5: Добавление рёбер
   - ЭТАП 6: Компиляция и выполнение
   - ЭТАП 7: Визуализация

**Преимущества:**
- Не требует API ключа
- Быстро выполняется
- Понятная структура

---

### Вариант 2: Пошаговое переписывание

**Файл:** `00_live_demo_step_by_step.py`

**Как использовать:**
1. Откройте файл в IDE
2. Раскомментируйте код по этапам
3. После каждого этапа запускайте и объясняйте

---

### Вариант 3: ReAct на LangGraph

**Файл:** `02_react_langgraph.py`

**Что показывает:**
- Тот же ReAct что в Лекции 13
- Но на LangGraph с графом состояний
- Условные переходы (agent → tools или end)

**Запуск:** `python 02_react_langgraph.py`

---

### Вариант 4: Human-in-the-Loop

**Файл:** `03_human_in_loop.py`

**Что показывает (НОВОЕ!):**
- Агент спрашивает подтверждение перед send_email
- Человек может отклонить действие
- Чего не было в AgentExecutor!

**Запуск:** `python 03_human_in_loop.py`

**Пример:** "Отправь email Ивану" → агент спросит подтверждение

---

### Вариант 5: Self-Correcting

**Файл:** `04_self_correcting.py`

**Что показывает (НОВОЕ!):**
- Генерация → Критика → Retry при низкой оценке
- Агент сам проверяет и улучшает ответ

**Запуск:** `python 04_self_correcting.py`

---

### Вариант 6: Plan-and-Execute

**Файл:** `05_plan_execute.py`

**Что показывает (НОВОЕ!):**
- Сначала планирование шагов
- Потом выполнение по одному
- Синтез финального ответа

**Запуск:** `python 05_plan_execute.py`

**Пример:** "Какая дата? Умножь день на 10"
