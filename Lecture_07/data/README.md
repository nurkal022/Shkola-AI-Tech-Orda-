# Тестовые файлы для демонстрации парсеров

Эта папка содержит примеры файлов разных форматов для демонстрации работы различных парсеров документов в LangChain.

## 📁 Содержимое

| Файл | Формат | Назначение |
|------|--------|------------|
| `sample.txt` | Plain Text | Демонстрация `TextLoader` |
| `sample.md` | Markdown | Демонстрация `UnstructuredMarkdownLoader` |
| `sample.html` | HTML | Демонстрация `UnstructuredHTMLLoader` |
| `sample.json` | JSON | Демонстрация `JSONLoader` |
| `sample.csv` | CSV | Демонстрация `CSVLoader` |
| `sample.xml` | XML | Пример структурированного XML |

## 🚀 Запуск демонстрации

```bash
cd Lecture_07
python 01_document_parsers.py
```

## 📋 Что демонстрируется

### TextLoader
- Загрузка простых текстовых файлов
- Автоматическое определение кодировки
- Базовые метаданные (source)

### DirectoryLoader
- Загрузка всех файлов из папки
- Фильтрация по расширению
- Прогресс-бар при загрузке

### UnstructuredMarkdownLoader
- Распознавание заголовков, списков, кода
- Два режима: `single` и `elements`
- Структурированное извлечение

### UnstructuredHTMLLoader
- Удаление HTML тегов
- Сохранение структуры текста
- Извлечение чистого текста

### CSVLoader
- Каждая строка → отдельный Document
- Все колонки в метаданные
- Конфигурируемый формат

### JSONLoader
- Навигация по JSON с помощью jq синтаксиса
- Извлечение массивов и объектов
- Гибкая структура данных

## 🔧 Добавление новых тестовых файлов

Для добавления новых форматов:

1. Создайте файл в соответствующем формате
2. Добавьте демонстрацию в `01_document_parsers.py`
3. Обновите эту документацию

Примеры форматов для добавления:
- `.pdf` (требует PyPDFLoader)
- `.docx` (требует Docx2txtLoader)
- `.xlsx` (требует UnstructuredExcelLoader)
- `.pptx` (требует UnstructuredPowerPointLoader)
