### Парсеры документов

```
┌─────────────────────┬────────────────────┬──────────────────────────────┐
│ Формат              │ Loader             │ pip install                  │
├─────────────────────┼────────────────────┼──────────────────────────────┤

│ .pdf                │ PyPDFLoader        │ pypdf                        │

```

### Методы чанкинга

| Метод | Скорость | Качество | Когда использовать |
|-------|----------|----------|-------------------|
| Fixed Size | ⚡⚡⚡⚡⚡ | ⭐⭐ | Быстрый прототип |
| Recursive | ⚡⚡⚡⚡ | ⭐⭐⭐ | **Универсальный (default)** |

### Trade-offs размера чанка

```
Маленькие чанки (256-512)        │  Большие чанки (1500-2048)
─────────────────────────────────┼─────────────────────────────────
✅ Точный поиск                  │  ✅ Много контекста
✅ Меньше токенов на запрос      │  ✅ Меньше API вызовов
✅ Быстрый поиск                 │  ✅ Сохранность смысла
❌ Потеря контекста              │  ❌ Шум в результатах
❌ Больше чанков = дороже        │  ❌ Дольше поиск
```

## 🚀 Быстрый старт

```python
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_community.document_loaders import TextLoader

# 1. Загрузка
loader = TextLoader("document.txt", encoding="utf-8")
docs = loader.load()

# 2. Чанкинг (рекомендуемые параметры)
splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,      # Символов
    chunk_overlap=200,    # 20% перекрытие
)
chunks = splitter.split_documents(docs)

# 3. Готово к индексации!
print(f"Создано {len(chunks)} чанков")
```

## 💡 Рекомендации

### По размеру чанка

| Задача | chunk_size | chunk_overlap |
|--------|------------|---------------|
| Q&A / FAQ | 500-800 | 100 |
| Документация | 1000-1500 | 200 |
| Книги / статьи | 1500-2000 | 300 |
| Код | 1000-1500 | 100 |

### По очистке текста

✅ **Делать:**
- Нормализация Unicode
- Удаление лишних пробелов/переносов
- Удаление HTML тегов
- Склеивание переносов слов (PDF)

❌ **НЕ делать:**
- Удаление стоп-слов
- Приведение к lowercase
- Удаление пунктуации

### По метаданным

**Обязательные:**
- `source` - источник документа
- `chunk_id` - идентификатор
- `created_at` - время создания

**Полезные для фильтрации:**
- `document_type`, `category`, `language`, `date`
