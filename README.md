# Generative AI Engineer Course

Комплексный курс по генеративному ИИ от основ до создания и развертывания сложных ИИ-агентов.

## 📋 Общая информация

- **Длительность**: 26 недель (104 академических часа)
- **Формат**: Online обучение
- **Уровень**: Продвинутый

## 🎯 Цели курса

Обучить студентов проектированию, созданию и развертыванию реальных приложений на основе генеративного ИИ: от RAG-систем и автономных агентов до готовых к продакшену облачных сервисов.

## 📚 Описание курса

Этот комплексный курс проведет вас от основ генеративного ИИ до создания и развертывания сложных ИИ-агентов. Вы освоите большие языковые модели, такие как GPT и Llama, изучите продвинутый промпт-инжиниринг и научитесь создавать мощные RAG-системы с использованием векторных баз данных.

Значительная часть курса посвящена разработке автономных агентов с помощью фреймворков LangChain и CrewAI. Через еженедельные практические проекты вы также изучите дообучение моделей (LoRA), создание производственных API на FastAPI, контейнеризацию с Docker и развертывание приложений в облаке.

По окончании курса вы будете обладать навыками для создания полноценных, реальных ИИ-решений.

## 🗂️ Структура курса

Курс разделен на две основные части, каждая из которых состоит из 13 недель с лекциями и практическими проектами.

---

## 🚀 Часть 1: Generative AI Engineer 1

### Неделя 1: Введение в Генеративный ИИ и большие языковые модели (LLM)
**Темы:**
- Фундаментальные концепции генеративного ИИ
- История и архитектура LLM
- Сравнение основных моделей (GPT, Gemini, Claude, Grok)
- Экосистема LLM с открытым исходным кодом (Llama, Mistral, Qwen, DeepSeek)
- HuggingFace Hub для поиска и применения моделей

**Проект 1:** Сравнение производительности ведущих LLM и оценка open-source моделей

### Неделя 2: Запуск LLM локально с помощью Ollama
**Темы:**
- Настройка и запуск LLM на локальном компьютере
- Преимущества локального выполнения (конфиденциальность, стоимость, кастомизация)
- Создание REST API для локальной модели

**Проект 2:** Настройка Ollama и создание REST API с клиентским приложением

### Неделя 3: Основы разработки приложений на базе LLM
**Темы:**
- Управление LLM-приложениями
- Реализация стриминга ответов
- Базовое логирование и отслеживание затрат
- Ключевые метрики производительности

**Проект 3:** Веб-приложение с стримингом ответов и логированием

### Неделя 4: Основы промпт-инжиниринга
**Темы:**
- Zero-shot, one-shot и few-shot промптинг
- Важность четких инструкций, ролей и форматирования

**Проект 4:** Классификация текста с помощью few-shot промптинга

### Неделя 5: Продвинутые техники промпт-инжиниринга
**Темы:**
- Chain-of-Thought (цепочка мыслей)
- Self-Consistency (самосогласованность)
- Tree of Thoughts (дерево мыслей)

**Проект 5:** Решение логических задач с Chain-of-Thought

### Неделя 6: Введение в LangChain
**Темы:**
- Основные компоненты LangChain
- Создание цепочек промптов
- Управление памятью и структурирование взаимодействий

**Проект 6:** Создание цепочки для генерации контента (идея → пост в блог → социальные сети)

### Неделя 7: Основы Retrieval-Augmented Generation (RAG)
**Темы:**
- Концепция RAG и ее важность
- Уменьшение галлюцинаций
- Базовая архитектура: загрузка, разделение, векторизация, хранение, извлечение

**Проект 7:** Базовая RAG-система для ответов на вопросы по документу

### Неделя 8: Подготовка данных и чанкинг
**Темы:**
- Стратегии чанкинга документов
- Компромиссы между размерами фрагментов
- Фиксированный, рекурсивный и семантический чанкинг

**Проект 8:** Анализ различных стратегий чанкинга на сложных документах

### Неделя 9: Введение в векторные базы данных
**Темы:**
- Специализированные БД для векторных представлений
- Pinecone, Qdrant, pgvector для PostgreSQL

**Проект 9:** Векторизация документов и семантический поиск

### Неделя 10: Реализация RAG с помощью pgvector и Supabase
**Темы:**
- Практическое руководство по pgvector
- Настройка базы данных до полного цикла извлечения и генерации

**Проект 10:** Полнофункциональное RAG-приложение с Supabase

### Неделя 11: Продвинутый поиск с Hybrid Search и RRF
**Темы:**
- Гибридный поиск (ключевые слова + семантический)
- Reciprocal Rank Fusion (RRF) для объединения результатов

**Проект 11:** Реализация гибридного поиска в RAG-системе

### Неделя 12: Оптимизация производительности RAG
**Темы:**
- Переранжирование документов
- Кеширование для ускорения ответов
- A/B-тестирование стратегий RAG

**Проект 12:** Добавление переранжирования и кеширования в RAG-приложение

### Неделя 13: Введение в ИИ-агентов и фреймворк ReAct
**Темы:**
- Определение ИИ-агента и его компоненты
- Сравнение агентов с паттернами рабочих процессов
- Фреймворк ReAct (Reason and Act)

**Проект 13:** Создание агента с инструментами (калькулятор, дата) с помощью ReAct

## 🚀 Часть 2: Generative AI Engineer 2

**Темы:**

**Проект 3:** Команда агентов для автоматизации создания контента

### Неделя 4: Интеграция инструментов: внешние API и веб-скрапинг
**Темы:**
- Практические навыки интеграции внешних API

**Проект 4:** Агент с интеграцией API погоды и новостей

- Создание высокопроизводительного бэкенда
