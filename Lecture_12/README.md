## 🎯 Ключевые концепции

### Что такое агент?

```
Агент = LLM + Tools + Reasoning

LLM (мозг):
  • Анализирует запрос
  • Решает какие инструменты использовать
  • Формирует ответ

Tools (инструменты):
  • Calculator - вычисления
  • RAG Retriever - поиск в документах
  • Custom tools - любые функции

Reasoning (рассуждения):
  • ReAct паттерн (Reasoning + Acting)
  • Агент "думает" перед действием
```

### ReAct паттерн

```
User: "Сколько будет 25 * 17?"

Agent:
  1. [THOUGHT] Это математический вопрос, нужен калькулятор
  2. [ACTION] Calculator
  3. [ACTION INPUT] "25 * 17"
  4. [OBSERVATION] Результат: 425
  5. [FINAL ANSWER] 25 * 17 = 425
```

## 💡 Важные моменты

### 1. Tool Description критична

Агент выбирает инструмент на основе описания:

```python
Tool(
    name="Calculator",
    description="Полезен для математических вычислений..."
)
```

**Хорошее описание:**
- Чётко объясняет когда использовать
- Приводит примеры
- Указывает формат входных данных

### 2. Verbose Mode

Включите `verbose=True` чтобы видеть "мысли" агента:

```python
AgentExecutor(..., verbose=True)
```

Это помогает:
- Понимать как агент работает
- Отлаживать проблемы
- Обучать студентов

### 3. Обработка ошибок

```python
AgentExecutor(
    ...,
    handle_parsing_errors=True,  # Автоматическая обработка
)
```

Агенты могут ошибаться:
- Неправильный выбор инструмента
- Ошибки парсинга
- Некорректные входные данные

### 4. Ограничения агентов

- Могут выбрать неправильный инструмент
- Могут не использовать инструмент когда нужно
- Зависимы от качества описаний инструментов
- Требуют валидации результатов

## 🔧 Технические детали

### Используемые компоненты LangChain

- `create_react_agent` - создание ReAct агента
- `AgentExecutor` - выполнение агента
- `Tool` - обёртка для функций
- `create_retriever_tool` - готовый tool для retriever
- `hub.pull("hwchase17/react")` - промпт для ReAct

### Модель

- `gpt-4o-mini` - быстрая и дешёвая
- Поддерживает function calling
- Хорошо работает с агентами

### База данных

- FAISS индекс из `Lecture_06`
- Книги Гарри Поттера
- Embeddings: `text-embedding-3-small`
